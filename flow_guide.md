결재 기준으로 흐름

민수가 Flow Designer에서 워크플로우를 만듭니다:

┌─────────────────────────────────────────┐
│ [Start 노드 클릭]                        │
│                                         │
│ 우측 속성 패널:                          │
│ ┌─────────────────────────────────────┐ │
│ │ 레이블: 권한 요청 폼                 │ │
│ │                                     │ │
│ │ 폼 필드 구성:                        │ │
│ │ [+ 필드 추가] 클릭                   │ │
│ │                                     │ │
│ │ 1. requester_name (text, 필수)      │ │
│ │ 2. system (select: HR/ERP/CRM)      │ │
│ │ 3. permission_level (number: 1-5)   │ │
│ │ 4. reason (textarea, 필수)          │ │
│ └─────────────────────────────────────┘ │
└─────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────┐
│ [Approval 노드 추가]                     │
│ - 승인자: manager@company.com           │
└─────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────┐
│ [Service 노드 추가]                      │
│ - URL: /api/permissions/grant           │
│ - Method: POST                          │
└─────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────┐
│ [End 노드 추가]                          │
└─────────────────────────────────────────┘
         ↓
[템플릿 저장] → "권한 요청 v1"


직원(김철수)이 워크플로우를 실행합니다:

1️⃣ 템플릿 선택
┌─────────────────────────────────────────┐
│ 워크플로우 템플릿 목록                   │
├─────────────────────────────────────────┤
│ □ 권한 요청 v1                          │
│ □ 구매 요청 v1                          │
│ □ 휴가 신청 v1                          │
│                                         │
│ [권한 요청 v1] 클릭 → [실행] 버튼       │
└─────────────────────────────────────────┘

2️⃣ Start 노드의 폼이 모달로 표시됨
┌─────────────────────────────────────────┐
│ 권한 요청 폼                      [X]    │
├─────────────────────────────────────────┤
│                                         │
│ 요청자 이름 *                            │
│ [김철수                              ]  │
│                                         │
│ 시스템 *                                 │
│ [HR                                 ▼]  │
│                                         │
│ 권한 레벨 * (1-5)                        │
│ [4                                   ]  │
│                                         │
│ 사유 *                                   │
│ [인사 정보 조회 및 수정 권한이           │
│  필요합니다.                            │
│                                        ]│
│                                         │
│          [취소]  [제출]                 │
└─────────────────────────────────────────┘

3️⃣ [제출] 클릭 시
→ POST /templates/:id/execute
{
  "formData": {
    "requester_name": "김철수",
    "system": "HR",
    "permission_level": 4,
    "reason": "인사 정보 조회 및 수정 권한이 필요합니다."
  }
}

4️⃣ 백엔드에서 process_instance 생성
ctx = {
  cursor: "start_node_id",
  nodes: [...],
  edges: [...],
  template_id: "uuid",
  formData: {  ← 여기에 저장!
    requester_name: "김철수",
    system: "HR",
    permission_level: 4,
    reason: "..."
  }
}

5️⃣ 엔진이 워크플로우 실행
Start 노드 → Approval 노드 → Service 노드 → End
