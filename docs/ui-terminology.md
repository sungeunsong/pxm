# 화면 용어 사전

화면에 보이는 말은 **보는 사람의 역할**에 맞춘다. 내부 코드값과 엔진 용어는 신청자·승인자 화면에
노출하지 않는다. 새 화면이나 문구를 만들 때 이 표를 따른다.

## 역할별 용어

| 내부 용어 | 신청자 | 승인자 | 설계자·운영자 |
|---|---|---|---|
| instance | 요청 | 요청 | 실행 |
| template / workflow | 업무 양식 | 업무 양식 | 워크플로우 |
| node | 노출하지 않는다 | 노출하지 않는다 | 노드 |
| task | 결재 | 결재 | 결재 |
| formSchema / Start 입력 | 입력 항목 | 요청 내용 | 입력 폼 |
| input preset | 저장한 입력값 | — | 실행 프리셋 |
| outcome | 처리 결과 | 처리 결과 | 처리 결과 |
| group namespace | — | — | 공개 이름 |
| entry point | — | — | 진입점 (종류: AI Tool, 게이트웨이 라우트) |
| terminate (본인이 요청) | 신청 취소 | — | — |
| terminate (운영자가 실행) | — | — | 강제 종료 |

## 상태 표시

코드값을 그대로 보이지 않는다.

| 코드값 | 표시 |
|---|---|
| Task `OPEN` | 승인 대기 |
| Task `OPEN` + 보류 | 보류 |
| Task `APPROVED` | 승인 완료 |
| Task `REJECTED` | 반려 |
| Task `CANCELED` | 취소 |
| 요청 `outcome: CANCELLED` + `REQUESTER_CANCELLED` | 신청 취소 |
| 요청 `outcome: CANCELLED` + 그 외 | 강제 종료 |
| 요청 `outcome: FAILURE` (실행 실패) | 처리 실패 |
| 요청 `outcome: FAILURE` (업무 실패 선언) | 처리 불가 |
| 결재 단계 `ALL` | 전원 승인 |
| 결재 단계 `ANY` | 1인 승인 |

## 기술 정보의 위치

요청 ID, 결재 노드 ID, 외부 요청 키, 결재 채널처럼 판단에 필요 없는 값은 지우지 않는다.
대신 **기본으로 접힌 "기술 정보"** 영역에 둔다. 문의·장애 대응 때 펼쳐서 전달하는 용도다.

## 알려진 불일치

현재 기록된 불일치는 없다. 새로 발견하면 위치와 문제를 표로 남기고, 해당 화면을 고칠 때 함께 바꾼다.
