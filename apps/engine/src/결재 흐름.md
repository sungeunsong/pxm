1. 사용자: 휴가 신청 폼 제출
   → formData: { type: "휴가", days: 3, approver: "김팀장" }

2. Start 노드 → Gateway 노드 (3일 이상?)
   → YES → Approval 노드

3. Approval 노드 도달
   → DB에 approval 레코드 생성
   → 김팀장에게 알림 발송
   → 워크플로우 WAITING 상태

4. 김팀장: 승인 페이지 접속
   → "3일 휴가 신청 - 홍길동"
   → formData 확인
   → "승인" 버튼 클릭

5. POST /approvals/:id/approve
   → DB 업데이트: decision = 'APPROVED'

6. 엔진: 폴링으로 승인 확인
   → 다음 노드로 진행 (Service: 인사팀에 알림)
   → End 노드
   → INSTANCE_COMPLETED

Option 2: 엔진에서 formData 활용 (30분-1시간) 🔧
Phase 3 시작! formData를 실제로 활용:

Gateway 노드에서 formData 참조 (예: ctx.formData.gender === "남자")
Service 노드에서 formData 사용 (HTTP Body에 포함)
로그에서 formData 확인

Option 3: 추가 폼 기능 (1-2시간) ✨

파일 업로드 필드
필드 검증 규칙 확장
